**Sound path**
- One 24-bit / 48 kHz output at 0 dB into the sound processor — BU32107 over I2S, BD37xxx through the SoC DAC (BD: 🧪 reports wanted). Volume and effects stay in the processor.
- No second output on the same PCM: no more `pcmC0D3p busy`, silent TTS or bus re-routing under music.
- Navigation and TTS prompts duck the music, also navigators that announce themselves as "assistant".

**Microphone and calls**
- SIM: handsfree echo cancelling, microphone ≈ +13 dB with the echo reference, handset bass back.
- Bluetooth: louder microphone, call at 0 dB.
- Telegram / WhatsApp: the factory VoIP record mode looped the input (stutter, crackle, silence) — fixed; the apps cancel echo themselves; louder on the speaker.
- Raw, unprocessed microphone for DSP apps (wDSP) and a clean voice-recognition input for assistants; headroom in every mode — trim with the car-settings sliders.

**Safety**
- Disable / remove restores the factory volume and audio parameters on the same boot.
