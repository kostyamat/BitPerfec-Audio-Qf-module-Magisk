🔴 **QF / K706 on UIS7862 only — NOT for UIS8581, NOT for any firmware other than QF or its MG clone.** The installer refuses everything else and changes nothing.

**Fixes**
- The "BitPerfect enabled" flag no longer drops to 0 on some boots. The boot check of the audio policies looked once, 2 s after boot, while the platform itself was restarting audioserver — it took the silence for "old policies", restarted audioserver and gave up. On those boots the calling module ran without its call path: echo on SIM calls. Now it waits for audioserver and restarts it only when it really runs without our policies.
- Installer: QF firmware (`QF…`) and its MG clone (`MG…`) only. A Topway unit — also UIS7862 — needed a reflash after the module; now any non-QF/MG firmware is refused.

**Updates from Magisk**
- From this version on Magisk shows an **Update** button for BitPerfect when a new release appears here. v5.6 users install v5.6.1 by hand once.
